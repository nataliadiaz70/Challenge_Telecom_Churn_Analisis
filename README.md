📊 Telecom X – Análisis de Churn.


📝 Descripción

Análisis exploratorio de datos sobre clientes de una empresa de telecomunicaciones con el objetivo de identificar factores asociados a la evasión de clientes (Churn) y generar insights que ayuden a mejorar la retención.

🎯 Objetivo

Comprender qué características de los clientes, contratos y servicios están relacionadas con el abandono del servicio.

📈 Principales Hallazgos

Mayor churn en contratos mensuales

Menor abandono en clientes con contratos de largo plazo

El precio y la falta de servicios adicionales influyen en la evasión
